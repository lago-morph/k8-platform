## Workflow

```mermaid
flowchart LR
    O[Orchestrator] --> A1[Subagent A:<br/>functionality doc<br/>own worktree]
    O --> A2[Subagent B:<br/>status doc<br/>own worktree]
    A1 --> M[Merge into main<br/>worktree]
    A2 --> M
    M --> R1[Review Round 1<br/>fresh context]
    R1 -->|inconsistencies?| F1[Apply fixes]
    F1 --> R2[Review Round 2<br/>fresh context]
    R2 -->|inconsistencies?| Fn[...]
    Fn --> Rn[Clean review]
    Rn --> PR[Open finalized PR]
```

The two research subagents ran in **parallel** in isolated git worktrees
to avoid stepping on each other. Each reviewer gets a fresh context (a
brand-new subagent) so it cannot rationalize earlier mistakes.
