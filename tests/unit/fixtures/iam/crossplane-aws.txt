# Required IAM actions for the Crossplane AWS provider (provider-family-aws v1).
# This list is intentionally minimal — the in-tree policy is broader. We
# assert the policy is at least a superset of these critical actions so a
# regression that drops a needed permission is caught.
eks:DescribeCluster
ec2:DescribeVpcs
ec2:DescribeSubnets
iam:GetRole
iam:CreateRole
iam:PassRole
iam:CreateOpenIDConnectProvider
# auto-012: the XSpokeAccess Composition tags the spoke OIDC provider, so
# CreateOpenIDConnectProvider-with-tags fails closed without Tag*. Observed
# live as "AccessDenied ... iam:TagOpenIDConnectProvider" at spoke-access sync.
iam:TagOpenIDConnectProvider
# auto-012: XSpokeAccess external-dns Role trust policy is rebuilt from the
# late-bound spoke OIDC issuer (UpdateAssumeRolePolicy); its inline RolePolicy
# is observed via GetRolePolicy each reconcile. Both failed closed live.
iam:UpdateAssumeRolePolicy
iam:GetRolePolicy
# auto-012: phase-5 XDatabase Composition provisions an RDS Instance; the
# crossplane policy carried no rds:* and the Instance MR failed closed at create.
rds:CreateDBInstance
rds:DescribeDBInstances
rds:DeleteDBInstance
secretsmanager:GetSecretValue
secretsmanager:DescribeSecret
# Phase 3 (docs/decisions/0003): the XPlatformCluster Composition
# provisions and DNS-validates a per-cluster wildcard ACM certificate, so
# the provider needs ACM issuance + Route53 record-write permissions.
acm:RequestCertificate
acm:DescribeCertificate
acm:DeleteCertificate
route53:ChangeResourceRecordSets
route53:GetChange
ec2:CreateSecurityGroup
ec2:DeleteSecurityGroup
secretsmanager:UpdateSecretVersionStage
