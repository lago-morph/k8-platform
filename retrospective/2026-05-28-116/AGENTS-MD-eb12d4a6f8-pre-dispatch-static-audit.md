# agent instruction

**Before dispatching a long-running CI workflow (chainsaw, terraform-test, integration suite), run a one-pass static audit for every known bug class the changed files could exhibit.** "Long CI iterations cost minutes per round and tend to surface bugs in layers — one fix unmasks the next. A pre-dispatch static audit (combinable into a single `grep` / `bash` invocation) catches multiple bug classes in one pass, in seconds. For Crossplane chainsaw changes the audit MUST include: (a) non-ASCII characters in tag-bound `description:` fields, (b) `set -o pipefail` / `[[ ]]` / other bash-isms in `script.content:` blocks, (c) `status.conditions:` array length not equal to 3 on v2 XR asserts, (d) `metadata.namespace:` literal vs binding mismatches, (e) `apply.resource.metadata.namespace: ($namespace)` literals which chainsaw schema validation rejects pre-substitution, (f) golden-vs-scenario data-value consistency for any goldens with `tags.Description` or other XR-propagated fields. Each of these can be a one-line grep; the audit is seconds. Skipping it costs ~5-15 minutes per chainsaw iteration per missed bug class."

*Grounded in: auto-003 PR #111 chainsaw iterations 1-5, each surfacing a different bug class. A pre-dispatch audit covering em-dashes + conditions arrays + bash-isms + namespace shapes + golden-scenario consistency would have caught most of the iterations in a single seconds-long pass.*

# justification

Chainsaw's layered failure mode (one fix unmasks the next) is documented in `retrospective/2026-05-28-113.md` Suggestion 4 ('Layered chainsaw failures hide each other; iterate before declaring done'). That rule said 'expect 2-3 iterations.' This rule says: 'before iterating at all, do a static audit that catches the bug classes you already know about.' The two rules compose — audit first, then iterate, then re-audit before declaring done. Cost of adopting: thirty seconds of grep per dispatch. Cost of not adopting: a chainsaw iteration per missed bug class, each five to fifteen minutes of CI plus log-fetch time plus diagnosis time. In the auto-003 PR #111 work this cost roughly forty minutes of wall-clock that a pre-dispatch audit would have eliminated.
