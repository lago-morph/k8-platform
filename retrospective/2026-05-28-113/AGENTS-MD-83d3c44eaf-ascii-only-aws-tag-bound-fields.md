# agent instruction

**ASCII-only in fields that flow into AWS Resource Groups Tagging.** "Any value that a Crossplane Composition propagates into `spec.forProvider.tags.*` on an AWS managed resource (or any field that ends up as an AWS tag value through any path) MUST contain ASCII characters only. AWS Resource Groups Tagging service rejects non-ASCII with `InvalidRequestException: Request rejected by the downstream tagging service`. The rejected character set includes em-dash `—` (U+2014), en-dash `–` (U+2013), curly quotes, and most Unicode punctuation. Use plain ASCII hyphen `-`, straight quotes, and ASCII-only descriptions in chainsaw scenarios, example XRs, integration test fixtures, and any production XR likely to be applied to AWS."

*Grounded in: auto-003 chainsaw run 26544123347, where em-dash in `chainsaw scenario 00 — happy path` propagated through the v2 Composition's `tags.Description` patch and AWS rejected `CreateSecret`, stalling all 3 platform-secret scenarios at 245s.*

# justification

The auto-003 chainsaw run against PR #105's branch surfaced this bug after ~15 minutes of CI wall clock per attempt. The em-dash had been there since the original scenario author wrote them; v1 Compositions evidently dropped non-ASCII tag values silently (or the v1 reconciler short-circuited before reaching CreateSecret), so the bug stayed latent through every prior chainsaw dispatch. v2 propagates tags correctly to the AWS API, which is when the rejection became visible. Cost of NOT having this rule: a full chainsaw iteration (~15 min) plus the time spent reading logs and tracing the propagation path before suspecting AWS-side validation. Cost of adopting: a `tests/unit/test_chainsaw_tag_chars.sh`-style enforcer (already added in PR #105 commit `d843915`) — one-time setup, ~50 lines, runs in <1s on every push. Plus a one-sentence rule in `AGENTS.md` so future authors don't re-introduce the bug. The asymmetry is large: 1s of unit-test runtime per push vs. ~15 min of chainsaw + 10 min of log-reading per regression.
