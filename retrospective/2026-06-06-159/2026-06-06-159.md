## Part 2 — Bugs found, each with the regression test added (TDD §6.2)

1. **mikefarah-yq glob `==`.** `select(.x == "*")` matches everything in CI's
   yq (v4.44.3) — `*` is a glob in the `==` RHS. Masked locally by python-yq.
   Fix: `test()` regex. Test: `test_kyverno_crd_kinds_qualified.sh` +
   `test_hub_addons_appproject.sh` wildcard checks. → AGENTS-MD rule.
2. **EKS auth-token expiry.** Static `aws_eks_cluster_auth` token (15-min TTL)
   expired during an 18m53s control-plane create → helm releases failed. Fix:
   `aws eks get-token` exec auth. Test: `test_eks_module_defaults.sh` tripwire.
   → AGENTS-MD rule.
3. **Kyverno bare CRD kind.** Policy matched `AppProject` (no group) → Kyverno
   can't resolve the GVR. Fix: `argoproj.io/v1alpha1/AppProject`. Test:
   `test_kyverno_crd_kinds_qualified.sh`. → AGENTS-MD rule.
4. **Async CRD ordering.** Policy 12 matched the RDS Instance CRD installed
   async by provider-aws-rds → would fail at policy apply. Fix: provider step
   waits for the CRD Established + `depends_on`. → folded into AGENTS-MD rule #3.
5. **external-dns subdomain filter on a parent-only zone.** `domainFilter =
   management.<domain>` with only the base `<domain>` zone + no
   `--aws-zone-match-parent` → matched zero zones, published nothing. Fix: the
   flag (hub + spoke). Test: `test_external_dns_disjoint_filters.sh` guard.
   → AGENTS-MD rule.
