# agent instruction

**Don't author live-coupled Crossplane spoke/cross-cluster infra blind — build it against the live cluster.** "Composition/MR work that depends on values only known at runtime — a late-populated XR `status` field (e.g. `oidcIssuer`, `certificateArn`), an OIDC provider `thumbprintList`, a full role ARN needing the account id, or a provider that isn't installed yet (provider-kubernetes) — must NOT be authored as final manifests without live iteration. patch-and-transform cannot gate on an empty status, so a single Composition that reads its own late status renders invalid resources. Split such work into a separate XR/Composition that consumes the ready cluster's status, and capture the exact MR shapes in a runbook to execute when the cluster is Active. Author the static, CI-verifiable parts (AppProject, Helm values, plain Applications, tests) now; defer the live-coupled parts to a runbook."

*Grounded in: auto-007 — two adversarial review rounds showed the spoke OIDC-provider/IRSA/access-entry/cert-delivery work had too many live-dependent unknowns (thumbprint, separate XSpokeAccess Composition, account-id EnvironmentConfig, provider-kubernetes) to author blind; it was captured as `decisions/auto-009` instead.*

# justification

The instinct under a "build everything" mandate is to author all the manifests up front. For live-coupled Crossplane infra that instinct produces confidently-wrong code: an OpenIDConnectProvider MR missing its required `thumbprintList`, an AccessEntry with a `principalArn` lacking the account id, a cert ConfigMap that needs provider-kubernetes that isn't installed, and a single Composition that patches `url: ""` because `status.oidcIssuer` isn't populated yet. Five adversarial reviewers caught all of these before a line shipped — evidence that the failure modes are real and not obvious from the schema. The rule preserves throughput (author the static half, which is most of the files and all of the tests) while routing the genuinely live-dependent half to a runbook executed with convergence feedback. The cost is honesty about what can't be verified blind; the payoff is not shipping a Composition that fails on first sync and burns a 20-minute reconcile per debug cycle.
