# agent instruction

**Do not trust `simulate-principal-policy` for resource-scoped IAM create deny tests.** "Do NOT use `aws iam simulate-principal-policy` as the firing proof for a resource-scoped IAM narrowing (e.g. `iam:CreateRole` on `role/<prefix>-*`): on a freshly-modified IRSA role it returns `implicitDeny` for EVERY action — even unambiguously-allowed `Resource:"*"` ones — so it cannot distinguish allow from deny. Prove the narrowing on the live CREATE path (drive the real controller to create a resource the policy must permit) plus a static source lint, and make any simulate-based check SKIP (never FAIL) when its in-scope positive control is itself denied."

*Grounded in: auto-015, where the simulate-based IAM deny check returned implicitDeny for `eks:DescribeCluster` (a `Resource:"*"` allow), proving the simulator unusable on the just-narrowed role.*

# justification

auto-015 narrowed the Crossplane provider role's IAM `Resource:"*"` and shipped a deny check built on `aws iam simulate-principal-policy --policy-source-arn <the role>`. Against the freshly-modified role the simulator returned `implicitDeny` with zero matched statements for *every* probe — including `eks:DescribeCluster`, which the role unambiguously allows on `Resource:"*"`. The rendered policy was verified correct, and the real IAM engine permitted the in-scope creates (the spoke OIDC provider + external-dns role were created under the narrowed policy moments later). So the simulator — not the policy — was wrong: it does not reliably evaluate a recently-changed IRSA role's attached managed policy. A deny check that trusts it produces a false FAIL (positive control denied) or a meaningless PASS. The rule costs nothing — it just redirects the firing proof to the live CREATE path (which is the authoritative, real-engine test anyway) and the static source lint, and makes the simulate-based check self-disable when its positive control is denied. Without the rule, an agent wastes a cycle debugging a "broken policy" that is actually fine, or worse, reverts a correct narrowing.
