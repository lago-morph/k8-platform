### Phase 1 — fix post-comment + bring up phases 0 and 1

## Part 4 — proposed ADRs

Architectural decisions made in this session that the user may want to record as ADRs. **Titles only — no specs.** Use the `adr` skill to author any of these if you decide they're worth recording.

- **App-of-apps ArgoCD bootstrap is owned by Terraform, everything else is GitOps.** Only `argocd/bootstrap.yaml` is `kubectl apply`ed by `terraform_data.argocd_bootstrap`; from then on ArgoCD self-manages `argocd/` (Apps + AppProjects). Grounded in PR #43.
- **PlatformSecret ASM key is `k8-platform/<XR-uid>`, not `<claim-namespace>/<claim-name>`.** UID over name avoids cross-namespace collisions when two claims share `metadata.name`. Grounded in adversarial-reviewer B finding adopted in PR #42.
- **`recoveryWindowInDays=0` on Composition-managed ASM secrets.** Optimizes for the abstraction's primary user (CI/dev/learning) rather than irreversible-delete safety; production secrets that need recovery are created out-of-band. Grounded in adversarial-reviewer B finding (the 7-day re-create block) adopted in PR #42.
- **Chainsaw uses real AWS scoped to a `k8-platform-chainsaw-*` prefix, not LocalStack.** TESTING-PLAN.md §"Layer 4" had this as an open question; the user selected real-AWS this session. Grounded in PR #41.
- **Chainsaw and management module pin the same Crossplane chart + AWS provider versions, cross-checked at unit-test time.** Drift between the two environments produces tests-green-here-broken-there results; the unit test extracts both default literals via `awk` and asserts equality. Grounded in `tests/unit/test_chainsaw_kind_config.sh` from PR #41.
- **CI workflows split by concern (terraform vs unit vs chainsaw), not bundled.** Each workflow is independently observable in the Actions UI and has its own path filter, so a Composition change doesn't wait through 15 minutes of management apply. Grounded in PRs #41 and #47/#48.
- **Audit-mode Kyverno policies live under `policies/audit/`; promote-to-enforce is an explicit later decision.** Grounded in PR #42's `09-platform-secret-namespace-allowed.yaml`.
